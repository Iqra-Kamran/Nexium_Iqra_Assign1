# Your Daily Quote App ✨

Your Daily Quote App is a beautiful and calming quote generator built using **Next.js**, **TypeScript**, and **Tailwind CSS**. It features daily inspirational quotes, ambient quote mode, dark/light theme toggle, and a galaxy-inspired background with interactive particles.

## 🌟 Features

- 🔄 **Daily Quote**: New quote every day based on the date.
- 🌌 **Ambient Mode**: Auto-rotating quotes every 6 seconds with smooth transitions.
- 🎨 **Galaxy Background**: Interactive white particles on a black background for a calming effect.
- 🌗 **Dark / Light Mode**: Toggle theme with a single click.
- 📚 **Category Filter**: Filter quotes by categories like Life, Success, Inspirational, etc.
- 💬 **Quote Explanation Tooltip**: Hover over quotes to get a brief explanation.
- 🖼 **Background Image**: Custom background using `images.jpg`.
- 📦 **Quotes stored locally** in `quotes.json` (no external API dependency).
